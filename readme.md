# Motion Test

AI-assisted Motion Canvas video generation pipeline for technical learning animations. The project generates a Motion Canvas TSX scene from a lesson prompt, previews it with Vite, and records the animation to an MP4 file.

## What This Project Does

- Uses an OpenAI-compatible chat completions API to generate `src/scenes/generatedScene.tsx`.
- Loads the generated scene into a Motion Canvas project at `2560x1080`.
- Runs a Vite dev server for previewing the scene.
- Uses Puppeteer and `puppeteer-screen-recorder` to capture the animation into `output/output.mp4`.

## Requirements

- Node.js 18 or newer
- npm
- Python 3 with a local `.venv` directory if you use the current render scripts unchanged
- An API key and base URL for an OpenAI-compatible API endpoint

## Setup

Install dependencies:

```bash
npm install
```

Create a `.env` file in the project root:

```bash
API_KEY=your_api_key_here
BASE_URL=https://your-openai-compatible-endpoint.example.com/v1
```

The pipeline currently reads `API_KEY` and `BASE_URL` from `.env`.

If you are using the provided render scripts as-is, create the local Python virtual environment they activate:

```bash
python3 -m venv .venv
```

The virtual environment is only activated by the shell commands in the scripts. The main project dependencies are installed through npm.

## Preview the Scene

Start the Motion Canvas/Vite preview server:

```bash
npx vite dev --port 9000
```

Open:

```text
http://localhost:9000/
```

The preview loads the Motion Canvas project from `src/project.ts`, which currently includes `src/scenes/generatedScene.tsx`.

## Generate and Render a Video

Run the full pipeline:

```bash
npx tsx pipeline.ts
```

This will:

1. Read `API_KEY` from `.env`.
2. Ask the configured model to generate a Motion Canvas TSX scene.
3. Write the generated code to `src/scenes/generatedScene.tsx`.
4. Start the render flow.
5. Save the final video to:

```text
output/output.mp4
```

The current test topic is hard-coded at the bottom of `pipeline.ts`:

```ts
const testTopic = "Kubernetes Cluster Architecture";
const testDetails = "Visualize a traffic spike hitting the K8s API server, triggering the scheduler to assign pods to an available worker node. Show node health status updates in real time.";
```

Edit those values to generate a different lesson animation.

## Render the Existing Scene Only

If `src/scenes/generatedScene.tsx` already contains the scene you want to record, run:

```bash
npx tsx render-video.ts
```

This starts Vite on port `9000`, opens the page in Puppeteer, records roughly 55 seconds of playback, and writes `output/output.mp4`.

## Debug the Browser Output

To capture the rendered page HTML for debugging:

```bash
npx tsx render-headless.ts
```

This writes the current page DOM to:

```text
dom.html
```

## Project Structure

```text
.
├── pipeline.ts                  # Generates Motion Canvas TSX and triggers rendering
├── render-video.ts              # Records the Motion Canvas preview to MP4
├── render-headless.ts           # Saves the preview page DOM to dom.html
├── vite.config.ts               # Vite + Motion Canvas plugin setup
├── src/
│   ├── project.ts               # Motion Canvas project entry point
│   ├── project.meta             # Motion Canvas preview/render metadata
│   └── scenes/
│       └── generatedScene.tsx   # Generated or edited scene
├── output/                      # Rendered videos are written here
└── dom.html                     # Debug DOM snapshot
```

## Notes

- `src/scenes/generatedScene.tsx` is generated by the pipeline and may be overwritten.
- The project does not currently define npm scripts, so commands are run with `npx`.
- `.env`, `.venv`, and `node_modules` are ignored by Git.
- If Puppeteer cannot launch Chrome in your environment, make sure required browser dependencies are installed and that Puppeteer completed its browser download during `npm install`.
- If port `9000` is already in use, update the port in `render-video.ts`, `render-headless.ts`, and the preview command.
