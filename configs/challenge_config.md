# Challenge Configuration

## Challenge Count Per Video

Final Decision:

* Exactly 1 challenge per video

Rules:

* Generate only one challenge for each completed educational video
* LLM must select the single best challenge type based on lesson content
* Do not generate multiple challenge types
* Do not generate challenge sequences
* Do not generate challenge sets

Selection priority:

* Choose the challenge that best reinforces the main learning objective of the lesson

Examples:

Process explanation
→ Arrange Steps

System architecture explanation
→ Build It Yourself

Decision/tradeoff explanation
→ Scenario Based

Definition/concept explanation
→ Multiple Choice

Relationship/association explanation
→ Match Items
